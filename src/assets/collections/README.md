# Collection photographs

Place genuine category overview images here when supplied. Name files after the
actual collection and view, in lowercase kebab-case. Until distinct category
photographs are supplied, collection pages use an appropriate supplied product
photograph as their visual reference.

Collection frames have different editorial crops: desktop side-by-side tiles use
portrait images, stacked tiles use wider images, and mobile tiles use 4:3 frames.
Keep the important subject clear of the outer edges and set `objectPosition` when
needed. Connect a public photo through the collection's `photo` field in
`src/data/catalogue.ts`. See `../README.md` for dimensions, alt text, and
responsive exports.
