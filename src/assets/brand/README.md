# Brand and editorial assets

The supplied Soft Heaven logo remains untouched at
`public/images/brand/soft-heaven-logo.png`. The website uses the
`public/images/brand/soft-heaven-logo-transparent.png` derivative, which removes
only the white canvas outside the supplied circular artwork. The favicon is
derived from the same transparent artwork at `public/soft-heaven-favicon.png`.
Keep the full aspect ratio; do not stretch the logo or crop it into a different
shape.

Use descriptive names such as `soft-heaven-wordmark.svg` only for a real supplied
asset. Hero photography uses a square frame; gifting and story photography use
portrait frames. Keep the subject within a crop that works at both mobile and
desktop widths. Consult `../README.md` before wiring an image into the homepage.
